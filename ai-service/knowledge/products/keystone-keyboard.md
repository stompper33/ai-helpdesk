# Keystone K87 mechanical keyboard

A wired tenkeyless mechanical keyboard with hot-swappable switches and RGB lighting, sold as "Mechanical keyboard".

## Keys not registering
If one or more keys do nothing when pressed, first try another USB port and cable, then test the keyboard on another computer. Next, pull the keycap and the switch with the included tools and press the switch back in firmly: a switch that is not fully seated is the most common cause. If the key still does not work with a known-good switch in that position, the circuit board is faulty: within 30 days of delivery it is replaced under the returns policy.

## Key chatter (double typing)
A key that types twice per press usually has dust in the switch. Blow compressed air under the keycap. If it continues, replace that switch with one of the four spare switches in the box; a switch that chatters within the first year is covered by the warranty.

## Replacing switches
The keyboard accepts any 3-pin or 5-pin MX-style switch. Unplug the keyboard first, pull the keycap, then pull the switch straight up with the switch puller. Insert the new switch with the pins straight.

## Lighting and shortcut keys
Fn + arrow keys change the lighting effect and brightness. Fn + Esc held for 5 seconds resets the keyboard to factory settings, which also fixes most lighting problems.
